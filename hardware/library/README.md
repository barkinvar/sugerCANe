# Rev A local libraries

**Scope: Rev A.** [Revision overview](https://github.com/barkinvar/candi-clone/blob/main/REV_A.md) · [All revisions](https://github.com/barkinvar/candi-clone/blob/main/REVISIONS.md).

Project footprints and 3D assets copied from KiCad10.0.6 libraries retain the KiCad library license (CC-BY-SA4.0 with the KiCad exception). Source: https://www.kicad.org/libraries/license/ . Most copied assets only change the 3D model path to a project-relative path. The Abracon ABM3B footprint retains the generic KiCad body/model but changes its pads to the manufacturer's recommended 1.8 × 1.2 mm lands on 4.0 × 2.4 mm centers, with a corresponding courtyard and silkscreen. Custom Wuerth and TI footprints use original geometry based on the linked manufacturer package drawings; see footprint_provenance.json. Print at 1:1 and compare with purchased components before ordering boards.
