# Rev H source and release status

The maintained source is available in [current/](../README.md), with the [handbook](../output/documentation/SC12_RevH_Handbook.pdf), native CAD, firmware, manufacturing exports and [layout and LED/header check summary](../reports/release_checks.json).

No refreshed full-validation release ZIP is published for H. The optional full power rerun was stopped before completion; the LED/header implementation and clearance/label updates have focused checks. Full-release packaging scripts retain their original requirement for complete power evidence. Prior released ZIPs remain unchanged in the [archive](../../archive/README.md).
