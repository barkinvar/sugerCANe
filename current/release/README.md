# Rev H source and release status

The maintained source is in [current/](../README.md), with native CAD, firmware, manufacturing exports, the [handbook](../output/documentation/SC12_RevH_Handbook.pdf) and [check summary](../reports/release_checks.json).

The [JLC sourcing candidate](../docs/JLC_SOURCING.md) has matched BOM/CPL and a [review-only package](../order/README.md). Final simulations are authorized and in progress. Current standalone power, input, firmware and PCB checks pass; the full coupled-startup traces are pending. U5 is assigned to user purchase and hand soldering from DigiKey, and C25/C26 now use 20 pF.

No full-validation release ZIP is published for H. Full-release packaging scripts still require complete passing power evidence. Prior released ZIPs remain unchanged in the [archive](../../archive/README.md).
