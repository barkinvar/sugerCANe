# Earlier Rev B connector iteration

This is the superseded Rev B design with angled Weidmüller /135 connectors. The current Rev B and B-2 use horizontal /90 connectors with different pin-row geometry. Do not mix these footprints or BOMs.

The complete historical [prototype ZIP](release/FRC_Sensor_CAN_RevB_Prototype.zip), [manifest](release/manifest.json) and [checksum](release/FRC_Sensor_CAN_RevB_Prototype.zip.sha256) are retained unchanged. Development scratch copies outside the release folder are ignored.
